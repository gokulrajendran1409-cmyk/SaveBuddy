# 💰 SaveBuddy

SaveBuddy is a modern Flutter-based personal savings tracker designed to help users monitor their savings, manage deposits and withdrawals, and achieve financial goals through an intuitive and engaging interface.

## ✨ Features

- 💵 Add deposits
- 💸 Record withdrawals
- 📜 Transaction history
- 📊 Savings analytics
- 📅 Calendar view
- 🎯 Savings goals
- 🏆 Achievement system
- 📈 Reports
- 🌙 Light and Dark theme
- 💾 Offline storage using SQLite

## 📱 Built With

- Flutter
- Dart
- Provider
- SQLite (sqflite)
- Shared Preferences

## 🚀 Getting Started

1. Clone this repository

```bash
git clone https://github.com/gokulrajendran1409-cmyk/SaveBuddy.git
```

2. Install dependencies

```bash
flutter pub get
```

3. Run the application

```bash
flutter run
```
